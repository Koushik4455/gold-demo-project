GOLDEN TRUST GOLD LOAN WEBSITE DEMO
Created as a static HTML/CSS/JavaScript concept for Kairav Infotech.

FILES
- index.html  : website structure and content
- style.css   : layout, colors, responsive/mobile styles
- script.js   : mobile menu, current year, demo WhatsApp enquiry form

HOW TO RUN ON WINDOWS 11
1. Extract the ZIP file (if you downloaded the ZIP).
2. Open the gold-loan-demo folder.
3. Double-click index.html. It should open in Chrome or Edge.
4. For editing, open the folder in VS Code: File > Open Folder.
5. Optional: install the VS Code extension "Live Server", right-click index.html, then choose "Open with Live Server".

BEFORE SHOWING THE CLIENT
- This is a concept/demo, not a production-ready financial services website.
- Replace Golden Trust with the client's real, approved business name and logo.
- Replace the sample phone number and Hyderabad location with verified details.
- In script.js, replace businessWhatsAppNumber in BOTH places with the client's WhatsApp number, digits only, including country code (India = 91). Example format: 9198XXXXXXXX.
- Update business hours, services, policies, and all claims only after client confirmation.
- The enquiry form opens WhatsApp; it does not save submissions to a database or send email.
- Do not add claims like “RBI approved”, guaranteed loan amounts, rates, or instant approval unless legally verified and approved by the client.
- Before production, arrange hosting/domain, HTTPS, privacy policy, accessibility checks, and any legal/compliance review appropriate to the actual lender.

TECHNOLOGY
Plain HTML5, CSS3 and JavaScript. Google Fonts are loaded from the internet; if offline, system fonts will be used.
